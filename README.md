# lab-setup
Week 1 – Project Module 1

Practical Lab Environment Setup

1. Project Overview

This project focuses on setting up a practical cybersecurity testing lab environment using Oracle VirtualBox and Kali Linux on a Windows laptop.

2. Project Objectives

- Set up a virtual lab environment.
- Install and configure Kali Linux.
- Configure VirtualBox NAT Network.
- Configure network settings.
- Enable clipboard and file sharing.
- Test internet connectivity.
- Create a virtual machine snapshot.

3. Tools and Technologies Used

- Oracle VirtualBox
- Kali Linux
- 7-Zip
- Windows Operating System

4. Lab Network Configuration

- Network Type: NAT Network
- Network Range: 10.0.0.0/24
- Kali Linux IP Address: 10.0.0.4/24
- Network Mode: Private Virtual Lab Network

5. Implementation Steps

1. Downloaded and installed Oracle VirtualBox.
2. Downloaded and imported the Kali Linux Virtual Machine.
3. Created a NAT Network with the range 10.0.0.0/24.
4. Configured the Kali Linux network settings.
5. Checked network connectivity.
6. Configured virtual machine settings.
7. Created a virtual machine snapshot.

6. Screenshots

Screenshots of the VirtualBox configuration, Kali Linux desktop, network settings and VM snapshot are included in the Screenshots folder.

7. Learning Outcomes

- Understood the basics of virtualization.
- Learned how to set up a Kali Linux virtual machine.
- Gained practical knowledge of NAT Network configuration.
- Practiced basic Linux network commands.
- Learned how to create and manage virtual machine snapshots.

8. Conclusion

This project provided practical experience in creating a basic cybersecurity testing lab using Oracle VirtualBox and Kali Linux. It helped develop an understanding of virtual machines, network configuration and the basic requirements for cybersecurity and ethical hacking practice.
